# Data Structures and Algorithms Labs

This repository contains my Data Structures and Algorithms (DSA) lab tasks and practice programs in C++.

## About

The labs in this repository were completed while studying the core data structures and algorithms, with a focus on understanding how each one works and when to use it.

## Topics Covered

- Arrays and strings
- Searching algorithms (linear search, binary search)
- Sorting algorithms (bubble, selection, insertion, merge, quick)
- Linked lists (singly, doubly, circular)
- Stacks and queues
- Recursion
- Trees and binary search trees
- Hashing
- Graphs (BFS and DFS)

## How to Compile and Run

You need a C++ compiler such as **g++** (MinGW on Windows) installed.

```bash
g++ filename.cpp -o filename
./filename
```

On Windows Command Prompt, run it with:

```bash
filename.exe
```

You can also open the code in **VS Code**, **Code::Blocks**, or **Visual Studio** and run it from there.
